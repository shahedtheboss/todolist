# 📝 To-Do List App

A simple, clean, and responsive to-do list web app built on **June 11, 2021**, as one of my very first web development projects.

## 🚀 Live Demo

🔗 [Check it out here](https://todo-prac.netlify.app/)

## 📌 Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Responsive design (works on mobile & desktop)
- Clean UI for beginner-level projects

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript

> This project was built without any frameworks to strengthen core web development skills.
